App or server

This is the only choice that matters, and it is about where the radio sits — not about how much you know.

Desktop app

The radio is plugged into this computer. It installs like any other application and runs its own server on a private port, so there is nothing else to set up. Take this one if you are undecided.

macOS, Windows and Linux installers

Portable server

The radio is somewhere else — a Pi in the loft, a box by the antenna, a machine left running. Unpack the archive, start sdrmm, and open port 8080 from any browser on the network. Same receiver, no window.

Run it as a service

The server listens on every interface without authentication by default. Set a token and HTTPS before it faces a network you do not trust.

There is no ARM Linux desktop bundle yet: on a Pi, run the server and open it in a browser. The rolling nightly follows main and can change saved-data formats without migrating them — use a stable release unless you are testing one.

Or install it with a package manager

These track the same releases, and they keep it updated with everything else on the machine.

Homebrew

The cask installs the app; the formula installs the headless server.

brew tap newspicel/tap
brew install --cask sdrminusminus

or, for a server
brew install sdrmm
brew services start sdrmm

Nix

Flake package for x86-64 and ARM64 Linux, with SoapySDR modules selectable.

nix profile install \
  github:Newspicel/sdrminusminus
sdrmm-desktop

NixOS module options

Container

Persists its database and recordings in a volume. Pass through the USB group that owns your radio.

git clone https://github.com/Newspicel/sdrminusminus.git
cd sdrminusminus
docker compose up -d

Once it has downloaded

  1. Install it

    macOS: open the disk image and drag SDR-- to Applications. Windows: run the installer — it is not code-signed yet, so SmartScreen asks first; choose More info, then Run anyway. Linux: chmod +x the AppImage, or sudo apt install ./SDR--*.deb. Servers: unpack the archive and run ./sdrmm.

  2. Open it

    The app opens its own window. The server prints its address — reach it at http://localhost:8080, or http://<machine>:8080 from another computer on the network.

  3. Patch a receiver

    Drop a Device node, select your radio, wire its IQ output into a channel and the channel into a speaker. If the radio is not listed, use Check hardware on the node or run sdrmm --doctor.
